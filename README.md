# 🏎️ Gesture Racer - Hand Gesture Racing Game

A fun racing game controlled by hand gestures using MediaPipe Hands AI.

## 🎮 How to Play

### Controls (Use BOTH hands):
| Gesture | Action |
|---------|--------|
| ✊🖐️ Hold right, open left | ← Move Left |
| 🖐️✊ Hold left, open right | Move Right → |
| 🖐️🖐️ Open both hands | ⚡ NITRO BOOST! |
| ✊✊ Close both fists | Hold position |

### Difficulty Levels:
- 😊 **Easy** - Slow speed, fewer obstacles
- 😐 **Normal** - Balanced gameplay
- 😈 **Hard** - Fast speed, more obstacles

## 🚀 Getting Started

1. Open `racing_game.html` in a browser
2. Allow camera access when prompted
3. Select difficulty level
4. Click **START GAME**
5. Use hand gestures to control the car!
